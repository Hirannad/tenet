# Retro

A log of the process, not of the notes. Newest entry on top. An entry goes here when a rule only
held because someone enforced it by hand: a draft came back `unclear` or was rejected on form, or
the user had to point a rule out. Rejecting a note on its merits is normal operation and does not
belong here.

Each entry says what deviated, which rule it touched, which error class it falls in, and what would
have caught it. The same rule or class twice means the rule is not working: it gets a mechanism
that fails when it is broken, or it is deleted.
